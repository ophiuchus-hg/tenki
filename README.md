# TORIANSE雪氷予報（GitHub Pages版）

TORIANSE（ウェザーニューズ）の雪氷予報CSVを、ブラウザ側で読み解いて表示する静的ページです。

## 仕組み

- `index.html` が、同じ場所に置かれた `forecast_short.csv`（短期予報）と `forecast_weekly.csv`（週間予報）を読み込んで表示します
- データを更新するときは、CSVを同名のまま差し替えてください。ページ側の変更は要りません
- CSVの形式はTORIANSEの「雪氷期短期予報」と「週間」のCSVダウンロードそのままです（短期=集計要素を含む形式、週間=通行止め基準を含む形式を自動で判別します）

## 表示内容

- 対象は長野エリアの7区間（坂城〜長野、長野〜須坂長野東、須坂長野東〜信州中野、信州中野〜豊田飯山、豊田飯山〜信濃町、安曇野〜麻績、麻績〜更埴JCT）
- 短期予報は72時間の天気・降雪量・気温・路温、週間予報は13期間の天気・降雪量・最高気温・最低気温

出典：TORIANSE（ウェザーニューズ）雪氷期短期予報・週間予報／エリア：長野
